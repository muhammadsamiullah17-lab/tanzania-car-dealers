# Tanzania Car Dealers

Website for Tanzania Car Dealers: used cars for sale in Tanzania, with WhatsApp enquiry buttons on every car.

## Edit the site

- **WhatsApp number, email, location:** `config.js`
- **Cars for sale:** `cars.js` (prices in TZS)

It is a plain static site (no build step). Open `index.html` in a browser to preview.

## Deploy

Pushes to `main` deploy automatically on Vercel.
